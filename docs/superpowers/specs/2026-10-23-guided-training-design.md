# 훈련 시작(가이드 러닝) 설계

## 왜
훈련표는 인터벌·템포 같은 훈련을 글로만 알려준다("워밍업 2km + 1km × 5 (사이 400m 조깅) + 쿨다운").
뛰는 동안 회차·거리·페이스를 스스로 세야 해서, 특히 대회를 처음 준비하는 사람에게 어렵다.
앱이 그날 훈련을 구간별로 음성 안내해 "시키는 대로만 뛰면 되게" 만든다.
대상은 초보와 대회 준비 러너 모두.

## 목표
- 러닝 탭의 기존 "오늘의 훈련" 카드(`RunScreen.kt`)에 **"▶ 훈련 시작"** 버튼 추가. 휴식일을 제외한 모든 훈련 날에 표시.
- 훈련 시작 시 그날 운동을 구간으로 나눠 안내:

| 종류 | 구간 | 안내 |
|---|---|---|
| 이지런·장거리 | 목표 거리 1구간 | 기존 페이스 알림 + 목표 거리 도달 시 "목표 달성" |
| 템포 | 워밍업 2km → 템포 25분 → 쿨다운(남은 거리) | 구간 전환 음성, 템포 구간에만 템포 페이스 알림 |
| 템포(대회 주) | 가볍게 3km → 대회 페이스 1km → 쿨다운 | 대회 페이스 구간에만 알림 |
| 인터벌 | 워밍업 2km → (빠르게 → 조깅) × N → 쿨다운 | "빠르게 3/5회차" 등, 빠른 구간에만 인터벌 페이스 알림 |
| 대회 | 대회 거리 1구간 | 대회 페이스 알림 |

  인터벌 세트는 훈련표 생성기와 같게: 5K/10K = 400m × 8 (조깅 200m), 하프/풀 = 1km × 5 (조깅 400m).
  쿨다운은 "운동의 총 거리(`Workout.distanceKm`)까지 남은 거리".
- 구간은 **거리** 또는 **시간** 기준(템포 25분만 시간). 거리는 GPS 누적 거리로 판정.
- 구간이 바뀔 때 진동 + 음성. 러닝 화면에 진행 표시(기존 `intervalText` 자리 재사용, 예: "빠르게 3/5 · 420m 남음").
- 마지막 구간을 마치면 "훈련 완료!" 음성 안내만 하고 **기록은 계속된다**(자동 종료 없음, 기존 초보 인터벌과 동일). 사용자가 종료·저장할 때 완료 상태였으면 그날 운동에 완료 표시(`setWorkoutDone`). 마지막 구간 전에 종료하면 완료 표시 없이 일반 기록으로만 저장.
- 페이스 알림: 훈련 모드에서는 기존 "오늘 훈련 기반" 알림을 쓰지 않고, 목표가 있는 구간(인터벌 빠른 구간·템포·대회 페이스·이지/장거리/대회 전체)에서만 그 구간 목표로 알린다. 워밍업·조깅·쿨다운은 알림 없음. 중복 알림 금지.

## 하지 않을 것 (non-goals)
- 일반 "러닝 시작"의 동작 변경 없음(자유 러닝 + 기존 오늘 훈련 기반 페이스 알림 그대로).
- 초보 걷기·달리기 프로그램(`IntervalPrograms.beginner`, 코칭 설정)은 그대로 둔다.
- 사용자가 직접 인터벌을 만드는 기능, 회차별 기록 화면은 이번 범위 아님.
- 이지런의 "100m 가속주 4~6회"는 안내하지 않는다(설명 문구로만 남음).

## 실패로 볼 것 (anti-goals)
- 훈련 시작을 누르지 않았는데 구간 안내가 나오는 것.
- 저장된 기존 훈련표(이미 사용자 기기에 있는 plan JSON)가 깨지거나 못 읽히는 것.
- 구간 안내 때문에 기존 km 안내·자동 일시정지·임시저장이 망가지는 것.

## 제약
- 순수 로직(구간 만들기, 현재 구간 판정)은 `core` 모듈에 두고 `core/src/test`에 테스트(기존 `IntervalTest.kt` 스타일).
- 서비스는 `RunTrackingService` 한 곳. 시작 시 "훈련 모드"임을 Intent extra로 받는다.
- 기존 plan JSON 호환: `Workout`에 필드를 추가한다면 기본값이 있어야 한다.

## 빌더 재량 (내 판단, 바꿔도 됨)
- 구간 정보를 어떻게 얻을지: (a) 생성기가 `Workout`에 구조화된 구간을 함께 저장(기본값 있는 새 필드, 옛 계획은 "목표 거리 1구간"으로 대체) 또는 (b) 운동 종류·목표 거리·총 거리로 그때 계산. 대회 주 템포처럼 설명이 다른 경우가 있어 (a)를 추천.
- 기존 시간 기반 인터벌 코드(`IntervalStep`, `updateInterval`)와 합칠지 별도로 둘지.
- 음성 문구 세부, 진행 표시 문구.
- (내 판단) 강제 종료 후 임시저장에서 복구된 기록은 일반 러닝으로 복구한다. 구간 위치는 저장·복원하지 않는다(임시저장 형식 변경 없음).
- (내 판단) 워밍업+본 구간이 이미 총 거리 이상이면 쿨다운 구간은 생략한다.
- (내 판단) 이미 완료된 날에도 버튼을 보여 다시 할 수 있다. 다시 하면 새 기록으로 저장되고 완료 표시는 유지.
- 일시정지 중에는 구간 진행도 멈춘다(거리·시간 모두 기존 경과값 기준).
