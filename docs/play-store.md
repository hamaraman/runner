# Play Console 등록 방법

러너를 Google Play에 처음 올리고, 이후 업데이트하는 순서.

## 출시 체크리스트

위에서부터 순서대로 체크한다. 자세한 입력값은 아래 각 단계에 있다.

- [x] 개발자 계정 생성·인증 (1단계)
- [x] 앱 만들기: 패키지 이름 `io.github.hamaraman.runner`, **무료** (2단계)
- [ ] 비공개 테스트 트랙에 `runner-0.6.1.aab` 업로드 (5단계)
- [ ] 테스터 12명 이상 추가, 참여 링크 공유 (5단계)
- [ ] 앱 설정: 개인정보처리방침·앱 액세스·광고·콘텐츠 등급·타겟층·뉴스·건강 앱 (3단계)
- [ ] 데이터 보안·광고 ID·Health Connect 권한 (3단계)
- [ ] 포그라운드 서비스(위치) 시연 영상 촬영·YouTube 일부 공개 링크 (3단계)
- [ ] 스토어 등록정보: 설명·아이콘·그래픽 이미지·스크린샷 (4단계)
- [ ] 비공개 테스트 검토 제출 → 승인
- [ ] 테스터 12명 이상 14일 연속 참여
- [ ] 프로덕션 액세스 신청 → 승인 (5단계)
- [ ] 프로덕션 출시 검토 제출 (6단계)
- [ ] AdMob에 Play 앱 연결 (7단계)

## 0. 준비물

| 항목 | 위치 |
|---|---|
| 업로드할 AAB | GitHub 릴리스의 `runner-<버전>.aab` (태그를 올리면 자동 생성). 첫 업로드는 [v0.6.1](https://github.com/hamaraman/runner/releases/tag/v0.6.1)의 `runner-0.6.1.aab` |
| 앱 아이콘 512×512 | `store/icon_512.png` |
| 그래픽 이미지 1024×500 | `store/feature_1024x500.png` |
| 휴대전화 스크린샷 1080×1920 | `store/screenshots/01~05_*.png` |
| 개인정보처리방침 URL | https://hamaraman.github.io/runner/privacy.html |
| 패키지 이름 | `io.github.hamaraman.runner` (첫 업로드 후 변경 불가) |

서명 키(`~/keys/runner-release.jks`, 비밀번호 `~/keys/runner-release.pass`)는 업로드 키다.
잃어버리면 업로드 키 재설정을 Google에 요청해야 하니 PC 밖에도 백업해 둔다.

## 1. 개발자 계정

1. https://play.google.com/console 에서 개발자 계정 생성 (등록비 25달러, 1회).
2. 신원 인증과 휴대전화 인증을 마친다.
3. 2023년 11월 이후 만든 **개인 계정**은 정식 출시 전에 비공개 테스트(테스터 12명 이상, 14일 연속)가 필요하다.

## 2. 앱 만들기

**모든 앱 → 앱 만들기**

- 앱 이름: `러너 - 러닝 기록 & 마라톤 훈련` (4단계의 앱 이름)
- 기본 언어: 한국어
- 앱 / **무료**
- 패키지 이름을 묻는 칸이 나오면 `io.github.hamaraman.runner`를 복사해 붙여 넣는다
- 선언 항목 모두 체크

> **무료/유료:** '유료'는 설치할 때 돈을 받는 앱이다. 광고 제거 같은 앱 안 결제는 무료 앱에
> 인앱 상품으로 붙인다. 무료로 게시한 앱은 나중에 유료로 바꿀 수 없지만, 인앱 결제로 수익을 내면 상관없다.
>
> **패키지 이름 오타:** 업로드할 때 "패키지 이름에는 io.github.○○.runner이(가) 있어야 합니다"가 뜨면
> 콘솔 앱의 패키지 이름이 틀린 것이다. 한 번도 게시하지 않은 앱은 **설정 → 고급 설정 → 앱 삭제**로 지우고 다시 만든다.

## 3. 앱 설정 (대시보드 → 앱 설정)

### 개인정보처리방침
`https://hamaraman.github.io/runner/privacy.html`

### 앱 액세스 권한
모든 기능을 로그인 없이 사용할 수 있음.

### 광고
예, 앱에 광고가 포함되어 있음 (AdMob 네이티브 광고).

### 콘텐츠 등급
카테고리 "기타"(유틸리티·생산성 등) → 폭력·성적 콘텐츠·도박·약물 모두 "아니요",
사용자 간 소통 "아니요", 위치 공유 "아니요", 디지털 상품 구매 "아니요".

### 타겟층
18세 이상만 선택. (13세 미만이 포함되면 가족 정책이 추가로 적용된다.)

### 뉴스 앱
아니요.

### 건강 앱
"활동 및 피트니스" 선택.

### 데이터 보안

앱 자체는 데이터를 기기 밖으로 보내지 않는다. 수집·공유 항목은 AdMob SDK 몫이다.
제출 전에 AdMob 공식 문서 "Google Play 데이터 보안 섹션 안내"와 한 번 대조할 것.

- 데이터 수집·공유 여부: 예
- 전송 중 암호화: 예
- 삭제 요청 방법: 데이터는 기기에만 저장되며 앱 안에서 삭제하거나 앱을 지우면 모두 삭제됨

| 데이터 유형 | 수집 | 공유 | 목적 |
|---|---|---|---|
| 대략적인 위치 (IP 기반, AdMob) | 예 | 예 | 광고 |
| 기기 또는 기타 ID (광고 ID) | 예 | 예 | 광고, 사기 방지 |
| 앱 활동·진단 정보 (AdMob) | 예 | 예 | 광고, 분석 |
| 정확한 위치 (GPS) | 아니요 | 아니요 | 기기 안에서만 처리 |
| 사진 | 아니요 | 아니요 | 기기 안에서만 저장 |

### Health Connect 권한
**앱 콘텐츠 → Health Connect 권한**에서 아래 쓰기 권한마다 사용 이유를 적는다. 읽기 권한은 쓰지 않는다.

| 권한 | 사용 이유 |
|---|---|
| 운동 쓰기 (`WRITE_EXERCISE`) | 사용자가 연동을 켜면 러닝 기록(시간·종류)을 Health Connect에 저장 |
| 운동 경로 쓰기 (`WRITE_EXERCISE_ROUTE`) | 러닝 기록과 함께 GPS 경로를 저장 |
| 거리 쓰기 (`WRITE_DISTANCE`) | 러닝 거리를 저장 |

### 광고 ID
예, 광고 목적으로 광고 ID를 사용함.

### 포그라운드 서비스 권한
`FOREGROUND_SERVICE_LOCATION` 사용 이유:

> 사용자가 '러닝 시작'을 누른 뒤 화면이 꺼져도 GPS로 거리·경로를 계속 기록하기 위해 사용합니다.
> 기록 중에는 알림이 표시되고, 러닝을 끝내면 즉시 중지됩니다.

러닝 시작 → 알림 표시 → 종료 장면을 담은 30초 정도 화면 녹화를 YouTube에 '일부 공개'로 올리고 링크를 넣는다.

## 4. 스토어 등록정보 (스토어 표시 → 기본 스토어 등록정보)

- 카테고리: 건강/운동
- 아이콘, 그래픽 이미지, 휴대전화 스크린샷 업로드 (준비물 표 참고)

아래 문구를 그대로 붙여 넣는다. 기능이 바뀌면 여기만 고친다.
설명에 다른 회사의 앱·브랜드 이름은 넣지 않는다(Play 메타데이터 정책).

**앱 이름** (30자 이내)
```
러너 - 러닝 기록 & 마라톤 훈련
```

**간단한 설명** (80자 이내)
```
GPS 러닝 기록, 음성 코칭, 대회 맞춤 훈련 계획까지. 마라톤 준비를 한 앱에서.
```

**자세한 설명** (4000자 이내)
```
러너는 매일의 러닝을 기록하고, 목표 대회까지 차근차근 준비할 수 있게 도와주는 러닝 앱이에요.

■ GPS 러닝 기록
• 거리, 시간, 평균 페이스를 실시간으로 보여줘요
• 화면을 꺼도 백그라운드에서 계속 기록해요
• 멈추면 자동 일시정지
• 달린 경로를 지도로, 1km마다 구간 페이스를 한눈에
• 전체 경로 지도로 그동안 달린 길을 모아 보기
• 경로를 GPX 파일로 저장하고 공유하기

■ 기록과 목표
• 최장 거리와 1km·5km·10km 개인 최고 기록을 자동으로 정리해요
• 주간 목표 거리를 정하고 진행 상황을 확인해요
• 몇 주 연속으로 달렸는지 보여줘요
• 새 기록을 세우면 음성으로 축하해줘요

■ 음성 코칭
• 1km마다 거리와 페이스를 음성으로 알려줘요
• 목표 페이스보다 빠르거나 느리면 알려줘요

■ 전국 대회 일정
• 전국 마라톤 대회 일정을 앱에서 바로 보고 검색해요
• 5K·10K·하프·풀 종목별로 골라보기
• 나갈 대회를 추가하면 D-day와 신청 여부를 관리해요

■ 대회 맞춤 훈련 계획
• 대회를 추가하면 가장 먼저 열리는 대회에 맞춰 훈련표를 자동으로 만들어요
• 직접 목표와 주간 거리, 주 몇 회 달릴지 정해 만들 수도 있어요
• 이지런, 인터벌, 템포런, 장거리를 균형 있게 배치하고 회복 주와 대회 전 테이퍼까지
• 달린 날은 훈련표에 자동으로 완료 표시

■ 러닝화 마일리지
• 신발별 누적 거리를 자동으로 계산해 교체 시기를 알려줘요
• 러닝을 마치면 오늘 신은 러닝화를 확인해요. 깜빡해도 바로 고칠 수 있어요

■ Health Connect
• 러닝 기록을 Health Connect로 보내 다른 건강 앱과 함께 볼 수 있어요

■ 개인정보
러닝 기록은 내 기기에만 저장되며, 별도 회원가입이 필요 없어요.
대회 일정 제공: 저스트런(justrun.co.kr)

러너와 함께 오늘도 한 걸음 더 달려보세요!
```

## 5. 비공개 테스트

1. **테스트 및 출시 → 테스트 → 비공개 테스트 → 트랙 만들기**
2. 테스터: 이메일 목록을 만들어 12명 이상 추가 (Google 계정 Gmail 주소).
3. **새 버전 만들기**
   - 처음이면 "Play 앱 서명 사용"을 선택한다. 우리 키는 업로드 키가 되고, 배포용 서명 키는 Google이 보관한다.
   - **App Bundle** 칸에 `runner-<버전>.aab`를 올린다. `20 (0.6.1)`처럼 버전이 표시되면 패키지 이름이 맞은 것이다.
   - 출시 이름은 자동으로 채워지는 값을 그대로 둔다.
   - 출시 노트 (첫 출시):
     ```
     <ko-KR>
     러너 첫 버전이에요.
     · GPS 러닝 기록과 음성 코칭
     · 전국 대회 일정과 대회 맞춤 훈련 계획
     · 개인 최고 기록, 주간 목표, 러닝화 마일리지
     </ko-KR>
     ```
   - **다음 → 저장 → 검토로 보내기**.
4. 테스터에게 참여 링크(웹/Android)를 보낸다. 테스터가 링크에서 "테스터 되기"를 누르고 Play에서 설치해야 인원에 잡힌다.
5. 12명 이상이 14일 연속 참여하면 **대시보드 → 프로덕션 액세스 신청**이 열린다.

## 6. 프로덕션 출시

프로덕션 액세스가 승인되면 **프로덕션 → 새 버전 만들기**에 같은(또는 더 새) AAB를 올리고 국가(대한민국 등)를 선택해 검토를 제출한다.
첫 검토는 며칠 걸릴 수 있다.

## 7. 출시 후 할 일

### AdMob 연결
AdMob 콘솔 → 앱 → 러너 → 앱 설정 → **앱 스토어 세부정보 추가**에서 Play 스토어 앱을 연결한다.
연결과 검토가 끝나야 실제 광고가 제대로 나온다.

### 휴대폰에 깔린 앱을 Play 버전으로 바꾸기
Play 앱 서명을 쓰면 Play에서 받는 앱은 Google 키로 서명되어, GitHub 릴리스 APK로 깐 앱 위에 덮어 설치되지 않는다.
앱의 **기록 백업**으로 zip을 저장 → 앱 삭제 → Play에서 설치 → **백업 불러오기** 순서로 옮긴다.

### 업데이트 내기
1. `app/build.gradle.kts`의 `versionCode`를 1 올리고 `versionName`을 바꾼다 (PR로 `main`에 병합).
2. 같은 버전으로 주석 태그를 올린다. 태그 메시지가 릴리스 노트가 된다.
   ```bash
   git tag -a v0.4.1 -m "v0.4.1

   - 변경 사항"
   git push origin v0.4.1
   ```
3. GitHub Actions가 서명된 APK·AAB를 릴리스에 올린다.
4. Play Console의 트랙(비공개 테스트 또는 프로덕션)에 새 AAB를 업로드한다.

### 매년 확인
Google Play는 매년 8월 말부터 업데이트의 최소 targetSdk를 올린다.
https://support.google.com/googleplay/android-developer/answer/11926878 를 확인하고 `compileSdk`/`targetSdk`를 맞춘다.
